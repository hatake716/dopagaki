# Google Play ストア掲載情報（下書き）

Play Console の「ストアの掲載情報」にそのまま貼れる下書き。文字数制限を守ってある。

## アプリ名（30 文字以内）

```
dopagaki - ながら見2画面ブラウザ
```

## 簡単な説明（80 文字以内）

```
動画を見ながらタイムラインを流し読み。上下2ペイン同時表示、没入特化のながら見ブラウザ。
```

## 詳しい説明（4000 文字以内）

```
dopagaki は、動画とタイムラインを 1 画面で同時に楽しむための「ながら見」ブラウザです。上ペインで動画サイトを再生しながら、下ペインで SNS のタイムラインをひたすらスクロールできます。

■ 特徴

・2 ペイン同時動作
下をスクロールしても上の動画は止まりません。境界線をドラッグすれば比率は 15%〜85% で自由に変更でき、次回起動時も復元されます。

・没入特化の画面設計
ステータスバー・ナビゲーションバー・サイトのメニューをすべて隠し、画面のほぼ 100% をコンテンツに使います。常設 UI は境界線ハンドル 1 本と最上部の薄いブランドバーだけ。

・統合コントロール
戻る操作は「最後に触ったペイン」に効きます。各サイトの操作メニューは、ペイン左端からのスワイプで縦型メニューとして呼び出せます（4 秒で自動的に隠れます）。

・動画はペイン内全画面
再生を始めると上ペインの枠いっぱいに自動で全画面化。下のタイムラインはそのまま操作できます。

・かしこいリンク振り分け
タイムライン内の動画リンクは上ペインで再生、動画サイト内の SNS リンクは下ペインで開きます。

・ライト / ダーク切り替え
ブランドバーをタップするとテーマがアニメーションで切り替わります。サイト側が追従しない場合も強制的に反転表示できます。

・引っ張って更新
タイムライン先頭で下に引っ張って再読み込み。

・ログイン状態・表示位置・設定はすべて端末内に保存されます。アプリ自体がデータを収集・送信することはありません。

■ ご注意

・本アプリは Web サイト（x.com / youtube.com）を WebView で表示するブラウザです。X 社および Google / YouTube とは無関係の非公式アプリであり、各サービスの商標はそれぞれの権利者に帰属します。
・各サービスの利用には、それぞれの利用規約・プライバシーポリシーが適用されます。
・サイト側の仕様変更により、一部の表示調整機能が一時的に効かなくなる場合があります。
```

## データセーフティの回答案

- データ収集: **なし**（アプリはユーザーデータを収集・送信しない）
- データ共有: **なし**
- 暗号化: 該当なし（送信データなし。WebView の通信はすべて HTTPS）
- 削除リクエスト: 該当なし（開発者はデータを保持しない）
- ※ WebView 内で表示されるサイト（X / YouTube）自身のデータ収集は「アプリによる収集」には該当しないが、審査で指摘された場合は上記の説明を添える
