## はじめに

YouTube を見ながら X（旧Twitter）のタイムラインも追いたい——スマホでこれをやろうとすると、アプリを行ったり来たりするか、小さなピクチャー・イン・ピクチャーで我慢するかの二択になりがちです。

「上で動画を流しっぱなしにして、下でタイムラインをひたすらスクロールしたい。それだけなのに」

というわけで、それ専用の Android アプリを作りました。**dopagaki（ドパガキ）** といいます。

▼画像: feature-graphic.png（アイキャッチ）

## dopagaki とは

X と YouTube を **1 画面で同時に表示・操作できる「ながら見」ブラウザ**です。

- 上ペイン: YouTube（デフォルトで画面の 1/3）
- 下ペイン: X（デフォルトで 2/3）
- 境界線をドラッグすれば比率は 15%〜85% で自由に変更

最大の特徴は「没入特化」の画面設計です。ステータスバー、ナビゲーションバー、X のヘッダーとタブバー、YouTube のメニュー——**普段画面を占領しているバー類をすべて隠して**、画面のほぼ 100% をコンテンツに使います。常に表示されるアプリ独自の UI は、ペインの境界線ハンドル 1 本と、最上部の細いブランドバーだけ。

▼画像: screenshot-1.png（実際の画面。上で動画を再生しながら下で X を読める）

下をスクロールしても上の動画は止まりません。「動画の続きが気になるけどタイムラインも見たい」という葛藤から解放されます。

## 主な機能

### 1. 境界線ハンドルだけで完結する操作

画面中央の境界線が唯一の常設コントロールです。

- **ドラッグ** … 上下の比率を変更（次回起動時も記憶）
- **ダブルタップ** … 1:2 の比率に一発で戻す
- **長押しして離す** … 最後に触ったペインを再読み込み

「戻る」はアプリ独自のボタンではなく、Android 標準のバックジェスチャーがそのまま**最後に触ったペイン**に効きます。動画を全画面にしていたらまず全画面解除、という優先順位も自動です。

### 2. 操作メニューは左端からスワイプで呼び出す縦型メニュー

X のメインメニュー（ホーム・検索・通知・DM…）や YouTube のメニューは普段隠れていますが、**ペイン左端の中央あたりから右にスワイプ**すると、画面左端に縦型メニューとして 4 秒間だけ現れます。縦配置なのでコンテンツの表示領域を一切奪いません。

▼画像: screenshot-2.png（左端に縦型メニューが表示された状態）

### 3. 動画は再生と同時にペイン内全画面

YouTube で動画の再生を始めると、**上ペインの枠いっぱいに自動で全画面化**します。「全画面」といっても画面全体を覆うのではなく、あくまで上ペインの中だけ。下の X はそのまま読めます。

### 4. リンクは適切なペインに自動振り分け

- X で流れてきた YouTube リンクをタップ → **上ペインで再生**（X のタイムラインはそのまま）
- YouTube の概要欄などの X リンク → **下ペインで開く**

2 つの世界を行き来しても、レイアウトは崩れません。

### 5. ロゴをタップでライト / ダーク切り替え

最上部の dopagaki ロゴをタップすると、テーマがアニメーションで切り替わります。サイト側のテーマ設定が固定になっていても、描画色を検出して**強制的に**反転させるので、必ず好みの明るさで使えます。

▼画像: docs/images/main.png（ダークテーマのイメージ）

### 6. こまかい没入支援もいろいろ

- X の「〜さんがポストしました」の通知ピルや、ホーム上部のスペース（音声ルーム）カルーセルを非表示
- YouTube のホームは X と同じように**下に引っ張って更新**できる
- 使用中は画面が消灯しない
- ログイン状態・表示していた URL・比率・テーマはすべて記憶して次回復元

## 注意事項

- dopagaki は x.com / youtube.com を WebView で表示する**非公式アプリ**です。X 社および Google / YouTube とは関係ありません
- アプリ自体はデータを一切収集・送信しません（[プライバシーポリシー](https://hatake716.github.io/dopagaki/privacy-policy)）
- サイト側の仕様変更で一部の表示調整が一時的に効かなくなる場合があります
- YouTube への Google ログインは WebView の制約で通らない場合があります（その場合は未ログインで視聴できます）
